ML anomaly screening — backend code, not this dashboard

The separate TrustGuard transaction path runs a scikit-learn IsolationForest (`trustguard-isolation-forest-synthetic-v1`) using a deterministic synthetic baseline dataset (`synthetic-normal-transaction-features-seed-20261104-v1`). Its anomaly score is not a calibrated fraud probability; this model is not production validated. `POST /v1/agent/authorize` only validates Skyfire tokens and does not invoke transaction scoring. This static page runs no model inference.

In the TrustGuard path, a high score or scoring/model failure places the already-authorized transaction on durable HOLD before provider dispatch. PayPal dispatch remains disabled by default.
